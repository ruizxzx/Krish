# Krish — Awwwards Portfolio

Fresh Next.js portfolio for ruizxzx/Krish.

Stack: Next.js, React, TypeScript, Three.js/React Three Fiber, GSAP, Lenis.

The page renders as normal HTML/CSS first. WebGL is dynamically loaded with SSR disabled and has a Canvas fallback, so a WebGL failure cannot blank the portfolio.

Run: npm install && npm run typecheck && npm run build
